## Ссылки

Формат: `[дата · выпуск время]`. Дата московская, время локальное внутри части.
Для многочастных сессий добавляется `P2`.

Каждая ссылка сверена с проверенной базой тезисов скриптом
`app/scripts/check_knowledge.py`. Если тезис позже отменён или уточнён, это
отражено в [99_устаревшие_советы](99_устаревшие_советы.md).
