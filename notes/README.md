# База знаний по стримам xk

Сжатая выжимка из архива стримов: не пересказ выпусков, а принципы, цифры и
кейсы, разложенные по темам. Каждый пункт снабжён ссылкой на источник: номер
выпуска и таймкод, например `[186 00:38]` или `[(42) 01:12]`.

## Как это собрано

- Источник — **146 полных заметок** из `streams/`, сделанных по auto-субтитрам
  и двум расшифровкам Whisper.
- Тезисы разделены по темам, повторы объединены, близкие формулировки сведены
  в один принцип.
- Ссылки сохраняют привязку к конкретному месту стрима, а не к заметке целиком.
- Сырые тематические выжимки лежат в [`_extracts/`](_extracts/) — по ним можно
  проверить любой пункт.

## Как пользоваться

- **Геймдизайнеру:** начать с `01`, `02`, `03`, затем `05` и `06`.
- **Разработчику:** `04` про скоуп, архитектуру и плейтесты.
- **Маркетологу/соло-разработчику:** `07`, `08`, затем `10`.
- **Перед запуском:** `07_маркетинг_steam.md`.
- **Для быстрого входа:** `00_главное.md`.

## Ограничения

- Таймкоды приблизительные: это auto-субтитры, отдельные слова и имена могли
  быть распознаны неточно.
- Советы привязаны к контексту 2024–2026 годов и к опыту xk; это не
  универсальные законы.
- 74 стрима пока без субтитров — они не вошли в синтез. Их аудио лежит в
  `app/whisper_queue/` и будет добавлено после Whisper.
- В документах есть противоречия между выпусками; они по возможности отмечены
  отдельно, а не сглажены.
