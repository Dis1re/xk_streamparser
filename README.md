# xk_files

Заметки по каждому стриму [xk](https://www.youtube.com/@xkoster) + попытка структурировать всю инфу со стримов

Все права на исходные видео и их содержание принадлежат xk и YouTube; здесь только конспекты с таймкодами и ссылками на источники. Информация в данном репозитории не является на 100% истиной, она пропущена через авто-субтирты ютуба (часть через нейросеть распозноющую речь) и нейросетью, вычленяющая и структурирующая текст стримов. 
Если собираетесь использовать данную информацию, то перепроверяйте лично, для каждого тезиса и фразы есть свой таймкод и название стрима на ютуб.

## Что внутри

```text
.
├── streams/   # заметки по сессиям
├── notes/     # тематическая база знаний
├── app/       # пайплайн
└── archive/   # старые версии
```

**[streams/](streams/)** — заметки по дням стримов: одна сессия = один файл. Сейчас готово 37 заметок. Список всех сессий и правила — в [streams/README.md](streams/README.md).

**[notes/](notes/)** — тематическая база знаний: геймдизайн, маркетинг, издатели, AI, производство, Лондон, книги, внешность и устаревшие советы. Начать: [notes/00_оглавление.md](notes/00_оглавление.md).

**[app/](app/)** — скрипты, которые собирают транскрипты, заметки и проверяют цитаты. Как устроено: [app/README.md](app/README.md).

**[archive/](archive/)** — старые версии заметок и базы. Сохранены для истории, пайплайном не используются.

## Как читать

Каждый тезис заканчивается ссылкой:

```text
[2026-10-31 · 186 00:12:00]
```

Это дата, выпуск и таймкод. По ним можно найти исходный стрим и проверить контекст.
