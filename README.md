# xk_streamparser

Архив стримов [xk](https://www.youtube.com/@xk): заметки по каждому выпуску и
тематическая база знаний, плюс пайплайн для скачивания, расшифровки и сравнения
субтитров.

Репозиторий не связан с автором канала. Все права на исходные видео и их
содержание принадлежат xk и YouTube; здесь только конспекты с таймкодами и
ссылки на источники.

## Что внутри

```text
.
├── app/          # приложение: скрипты, данные, модели, Whisper-очередь
├── streams/      # заметки по каждому стриму
└── notes/        # тематическая база знаний
```

### streams/ — заметки по выпускам

**225 записей:** 146 полных конспектов, 74 заглушки «без субтитров» и
5 отсутствующих выпусков.

- нумерованные выпуски: **#186–#100**;
- старые стримы без номера: бонусная нумерация **`(1)`–`(127)`**;
- каждый конспект содержит таймкоды и источник: `auto`, `Whisper`,
  `без субтитров` или `отсутствует`.

Начать: [streams/README.md](streams/README.md).

### app/ — пайплайн

- `fetch.py` — метаданные, субтитры и аудио через `yt-dlp`;
- `vtt.py` — парсер WebVTT и очистка повторов;
- `export_text.py` — VTT → минутный транскрипт;
- `transcribe.py` — faster-whisper: JSONL/TXT/VTT;
- `compare.py` — сравнение auto-субтитров и Whisper;
- `download_whisper_audio.py` — очередь аудио для стримов без субтитров.

Подробности: [app/README.md](app/README.md).

## Быстрый старт

Нужны Python 3.12, `ffmpeg` в PATH и (опционально) NVIDIA GPU.

```powershell
uv sync --python 3.12 --extra cuda
cd app
.\.venv\Scripts\python.exe scripts\fetch.py "https://www.youtube.com/watch?v=..."
```

Все команды приложения выполняются из папки `app`.

## Whisper-очередь

Для 74 стримов без auto-субтитров подготовлено аудио: **216,7 часов**, mono
16 kHz, AAC. Аудио и модели **не входят в репозиторий** — они слишком большие.

- список и инструкции: [app/whisper_queue/README.md](app/whisper_queue/README.md);
- манифест: [app/whisper_queue/manifest.json](app/whisper_queue/manifest.json);
- скачать заново: `python scripts/download_whisper_audio.py` из `app/`.

Локально использовался `faster-whisper` + `large-v3-turbo` на GTX 1650
(`int8_float16`), RTF ≈ 0,08–0,11. На RTX 4090 ожидаемо в 5–10 раз быстрее.

## Как собраны заметки

- Основной источник — YouTube auto-captions.
- Для двух выпусков без субтитров — локальный faster-whisper.
- Таймкоды приблизительные: ASR путает имена, сленг и английские вставки.
- Заметки — выжимка идей, а не пересказ; фокус на геймдеве, геймдизайне, AI,
  маркетинге, практических приёмах и жизни в Лондоне.
- 74 выпуска пока без субтитров; они станут доступны после Whisper.

## Ограничения

- Это не истина в последней инстанции: советы привязаны к контексту 2024–2026
  и опыту xk.
- В базе знаний встречаются противоречия между выпусками; они не сглажены.
- Скачивание чужих VOD через `yt-dlp` может нарушать ToS YouTube. Используйте
  материал для личного обучения и уважайте права автора.
