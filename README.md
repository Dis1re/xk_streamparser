# xk_files

Заметки по каждому стриму [xk](https://www.youtube.com/@xkoster) + попытка структурировать всю инфу со стримов

Все права на исходные видео и их содержание принадлежат xk и YouTube; здесь только конспекты с таймкодами и ссылками на источники. Информация в данном репозитории не является на 100% истиной, она пропущена через авто-субтирты ютуба (часть через нейросеть распозноющую речь) и нейросетью, вычленяющая и структурирующая текст стримов. 
Если собираетесь использовать данную информацию, то перепроверяйте лично, для каждого тезиса и фразы есть свой таймкод и название стрима и ссылка на ютуб.

## Что внутри

```text
.
├── app/          # пайплайн: скрипты, задания, транскрипты, доказательства
├── streams/      # заметки по сессиям: один файл = один день стримов
├── notes/        # тематическая база знаний
└── archive/      # старые версии заметок и базы
```

### streams/ — заметки по сессиям

**205 сессий, 220 частей.** Сессия — это один день стримов: части и перезапуски,
между которыми меньше трёх часов, склеиваются в один файл. Дата — день первого
старта по Москве.

- **36 готовых заметок** — проверенных, с цитатами и таймкодами;
- **99 сессий** с полными субтитрами ждут разбора;
- **3 сессии** расшифрованы частично;
- **67 сессий** без субтитров ждут Whisper;
- **5 номеров отсутствуют** в архиве: #104, #108, #113, #125, #153.

Каждая заметка содержит дату, тип стрима, части, VOD, длительность и разделы:
«Главное», «Геймдев и геймдизайн», «AI и рынок», «Маркетинг и Steam»,
«Лондон / Англия», «Книги, статьи, люди», «Внешность и уход», «Цитаты»,
«Что унести в практику». Пустые разделы удаляются.

Ссылка на тезис выглядит так:

```text
[2026-10-31 · 186 00:12:00]
[2025-06-24 · (39–40) P2 00:06:00]
```

Дата — московская, время — локальное внутри части.

Реестр сессий: [`streams/_sessions.json`](streams/_sessions.json). Шаблон:
[`streams/_template.md`](streams/_template.md). Подробнее:
[streams/README.md](streams/README.md).

### app/ — пайплайн

**Сессионизация и время**

- `scripts/sessionize.py` — склейка частей в сессии по разрыву больше трёх часов,
  сборка транскриптов и реестра `streams/_sessions.json`;
- `scripts/tz.py` — Europe/London с DST и Москва UTC+3;
- `scripts/fetch_times.py` — реальные даты старта через `yt-dlp` (нужен прокси);
- `scripts/make_jobs.py`, `scripts/next_batch.py` — задания и очередь.

**Заметки**

- `prompts/extract_notes.md` — извлечение заметки и доказательств;
- `prompts/verify_notes.md` — независимая проверка по полному транскрипту;
- `scripts/apply_verdicts.py`, `scripts/apply_verdicts_to_note.py` — применение правок;
- `scripts/finalize_session.py` — правки + финальная сверка.

**Проверки**

- `scripts/check_notes.py` — даты, ссылки, части, таймкоды, дословность цитат;
- `scripts/check_all.py` — прогон по всем готовым заметкам;
- `scripts/check_knowledge.py` — сверка ссылок в `notes/` с базой тезисов;
- `scripts/session_usage.py` — расход токенов и время по сессии.

**Субтитры и Whisper**

- `scripts/fetch.py`, `scripts/vtt.py`, `scripts/export_text.py`;
- `scripts/transcribe.py`, `scripts/compare.py`;
- `scripts/download_whisper_audio.py`.

Данные: `app/data/_sessions/` (транскрипты), `app/data/claims/` (доказательства
и вердикты), `app/data/claims_all.jsonl` (общая база тезисов),
`app/data/jobs/` (задания).

### archive/ — старые версии

- `archive/streams_v1/` — прежние заметки по выпускам;
- `archive/notes_v1/` — прежняя база знаний;
- `archive/pilots/` — ранние эксперименты.

Старое сохранено для истории и не используется пайплайном.

## Как собраны заметки

1. Транскрипт режется на сессии: части с разрывом меньше трёх часов считаются
   одним стримом.
2. Агент читает полный транскрипт и пишет заметку и `claims.json` — по элементу
   на каждый пункт, с дословной цитатой, временем, областью применения и
   условиями.
3. Другой агент независимо проверяет каждый пункт по полному транскрипту и
   выносит вердикт: подтверждён, исправлен, отклонён или неоднозначен.
4. Детерминированные скрипты проверяют даты, ссылки, части, таймкоды и
   дословность цитат.
5. Исправления применяются к заметке, после чего сверка повторяется.

Имена восстанавливаются только там, где оригинал однозначен. Если однозначности
нет, остаётся написание из транскрипта. Конкретное имя никогда не заменяется
общим словом.

## Ограничения

- Это не истина в последней инстанции: советы привязаны к контексту 2024–2026
  и опыту xk, также возможны искажения нейросетью/авто-субтитрами и тд.
- Используйте материал для личного обучения и уважайте права автора.
- Если собираетесь использовать данную информацию, то перепроверяйте лично, для каждого тезиса и фразы есть свой таймкод и название стрима на ютуб.
