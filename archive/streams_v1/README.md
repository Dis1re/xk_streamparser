## Как это сделано

- Заметки собраны по auto-субтитрам YouTube или по локальному Whisper, если
  субтитров не было. Таймкоды приблизительные, отдельные слова могли быть
  распознаны неточно.
- Фокус — геймдев, геймдизайн, AI, маркетинг и всё, что можно унести
  в практику. Это не пересказ стрима.
- Сырые данные лежат в `app/data/<video_id>/`: аудио, субтитры, очищенные
  транскрипты, сравнения и отчёт по ASR.
- Пайплайн: `app/scripts/` (`fetch.py`, `vtt.py`, `export_text.py`,
  `transcribe.py`, `compare.py`).
- Аудио для будущего Whisper лежит в `app/whisper_queue/`: имена вида
  `<номер>_<название>.m4a`, манифест — `app/whisper_queue/manifest.json`.
  Скачивание: `app/scripts/download_whisper_audio.py`.

## Формат

Один файл = один стрим: `<номер>_<название>.md`.

Для отсутствующих выпусков: `<номер>_отсутствует.md`.  
Для пропущенных из-за отсутствия субтитров: `<номер>_без_субтитров.md`.

Старые стримы без номера идут после #100 и нумеруются в скобках: `(1)`, `(2)`
и так далее от новых к старым. Файлы называются `bonus_01_<название>.md`,
`bonus_01_без_субтитров.md` и т.п.
