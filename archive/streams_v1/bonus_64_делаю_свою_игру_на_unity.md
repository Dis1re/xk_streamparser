## Unity и нодовая система

- **00:43–00:45** — Yarn и Ink не подходят для ивентов с 4 фиксированными опциями; xk пилит свой костыль на нодах через xNode.
- **00:58–01:00** — у ScriptableObject больная сериализация: переименовал переменную — все диалоги пропали.
- **01:04–01:05** — хоткеи Rider: Ctrl+N — класс по имени, Shift+Shift — поиск, Ctrl+Alt+←/→ — назад по местам редактирования.
- **01:39–01:40** — иконки в инспекторе — это просто эмодзи в названии поля: дефолтный шрифт Unity их рисует.
- **01:40–01:43** — UI в мире: Canvas кладётся на 3D-объект, сверху UI-камера; так делают «компьютеры» в симуляторах.
- **01:51** — с корутинами дебаггер в Unity почти не работает, проще выводить всё через лог.
- **02:29–02:31** — дефолтные стрелки xNode меняются в настройках (Straight / Bezier), лучше дефолта всё равно ничего нет.
- **03:01–03:02** — партикл не вращался из-за Render Alignment = Vertical Billboard; лечится сменой на обычный Billboard.
- **03:06–03:07** — «живая» трава — это шейдер со смещением UV по синусоиде, а не анимация.
- **03:08–03:10** — сидированный рандом: сид хранится в сейве, перед генерацией сохраняется и переинициализируется.
