# streams/ — заметки по сессиям

Один файл — один день стримов. Части и перезапуски, между которыми меньше трёх
часов, считаются одной сессией; дата — день первого старта по Москве.

## Что здесь есть

- **41 заметка** из 206 сессий;
- **95 сессий** с полными субтитрами ждут разбора;
- **3 сессии** расшифрованы частично;
- **67 сессий** без субтитров ждут Whisper;
- **5 номеров** отсутствуют на YouTube: #104, #108, #113, #125, #153 — видео с ними не найдены.

Заметок-заглушек нет: если сессия ещё не разобрана, её просто нет в папке.
Полный список сессий — в [`_sessions.json`](_sessions.json).

## Имена файлов

```text
<выпуск>_<название>.md
```

Примеры: `186_18_игр_за_180_минут_...md`, `bonus_46_Геймдев_бизнес_QA_Dicewood.md`.
Бонусные выпуски получают префикс `bonus_`, чтобы не пересекаться с номерами.

## Формат заметки

В шапке: дата, тип стрима, части, VOD, длительность, канал, гость, источник
субтитров. Дальше — разделы с пунктами:

```text
- **00:12:00** — Тезис. `[2026-10-31 · 186 00:12:00]`
```

Для многочастной сессии время локальное внутри части и указывается часть:

```text
- **00:06:00** — Тезис. `[2025-06-24 · (39–40) P2 00:06:00]`
```

## Реестр

`_sessions.json` — канонический список: `session_id`, `label`, даты в UTC и
МСК, части, длительности, пути к транскриптам, признаки наличия субтитров.

Шаблон новой заметки — [`_template.md`](_template.md).

## Как проверяются заметки

Каждый пункт опирается на дословную цитату из транскрипта и проходит
независимую проверку вторым агентом. Затем детерминированный скрипт проверяет
даты, ссылки, части, таймкоды и дословность цитат. Подробнее — в корневом
[README](../README.md) и `app/README.md`.
